# Release notes

## v1.1.0

_18 Nov 2026_

### Breaking changes

- Python 3.8, 3.9 and 3.10 are no longer supported, and `pygments-djc` now requires Python 3.11 or later. On an older Python, `pip install pygments-djc` installs v1.0.1.

### Feat

- You can now use `pygments-djc` on Python 3.14.

## v1.0.0 - First release

_11 Feb 2025_

### Feat

- `djc_py` and `djc_python` code block - Syntax highlighting for Python code that contains Component classes with HTML / CSS / JS inlined blocks.
